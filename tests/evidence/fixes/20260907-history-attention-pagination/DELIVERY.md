# 历史问答加载与首页已处理会话修复

## 这次给用户带来了什么

向上查看旧会话时，每次加载都会真正推进到更早的用户问题和回答；折叠的思考与工具记录不再单独占满一页。

首页会话点击“处理完成”后，状态保存在服务端；JSONL 文件被回填或触碰不会再让旧会话在另一台设备上重新出现。“全部处理完成”现在会处理全部待处理会话，不再只处理首页的 100 条。

## 如何验收

1. 打开一个含大量思考和工具调用的长会话，向上滚动加载历史。
2. 确认每次加载都能看到更早的用户问题和回答，不会只出现折叠过程。
3. 返回首页，点击“全部处理完成”。
4. 页面显示“暂无待处理会话”；换一台设备访问同一服务后仍应保持为空。

## 修复前后对比

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 长会话上滑 | 一页可能只有折叠思考和工具调用 | 一页至少推进到完整问答上下文 |
| 已处理会话 | 文件时间变化后可能重新出现 | 只有真实新对话才会重新出现 |
| 全部完成 | 只确认首页最多 100 条 | 服务端一次确认当前全部会话 |

## 已知限制

跨设备一致性指连接同一个 ozw 服务的多个浏览器；两个独立部署不共享数据库，不会自动同步。
