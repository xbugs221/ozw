# 待处理会话卡片信息完善

## 这次给用户带来了什么

待处理会话卡片不再显示 Provider 图标，改为显示最后活动时间。包含多轮请求的会话会完整显示首条和末条请求，并在两者之间用 `...` 表示省略内容。

## 如何验收

1. 打开首页“待处理会话”。
2. 查看包含两轮用户请求的第一张卡片。
3. 应看到活动时间、项目名、完整首条请求、`...` 和完整末条请求；实际页面与预期一致。
4. 向右滑动卡片，卡片仍能正常标记为处理完成并从列表移除。

## 修复前后对比

修复前只有首条请求，卡片左上角显示 Provider 图标。修复后左上角显示活动时间，首条与末条请求均完整呈现。

## 可直接查看的证据

- [修复前](./before/card.png)：看第一张卡片，只有首条请求，左上角仍是 Provider 图标。
- [修复后](./after/card.png)：看第一张卡片，活动时间替代了图标，并出现 `...` 与完整末条请求。

## 已知限制

中间的历史请求与助手回复按产品要求折叠为 `...`，不会在首页卡片中逐条展开。
