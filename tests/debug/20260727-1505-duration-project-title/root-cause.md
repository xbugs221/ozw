# 耗时单位与 TUI 项目标题

## 用户可感知场景

- 短耗时仍显示无意义的零小时、零分钟。
- Shell/TUI 顶部固定显示“Project”，无法直接识别当前项目。

## 调用链与模块责任

- `turnSummaryFormatting` 负责折叠摘要的时间文本。
- `MainContentTitle` 负责 Shell/TUI 顶部标题。

## 关键证据

- 时间函数固定输出三段单位。
- 标题默认分支写死返回 `Project`，未使用已经传入的 `selectedProject`。

## 根因与置信度

Confirmed：两个展示函数都忽略了现有上下文所能提供的更精确信息。

## 修复方案

- 少于一分钟仅显示秒；少于一小时显示分钟和秒；其余显示时分秒。
- Shell/TUI 与预览页显示项目展示名，缺失时回退内部名称。

## 回归测试

- 覆盖 48 秒、1 分 23 秒、1 小时 2 分 3 秒。
- 验证 Shell 标题优先使用项目展示名，并保持主页、文件标题不变。

## 验证结果

- 渲染测试：24/24
- 标题测试：1/1
- 生产构建：通过
- 服务重启后真实浏览器显示：`耗时 58秒`、`耗时 01分钟06秒`
- Shell/TUI 顶部显示具体项目名：`ozw`
- 浏览器控制台：0 个错误
- 截图：`screenshots/duration-units.png`、`screenshots/tui-project-title.png`

无。
